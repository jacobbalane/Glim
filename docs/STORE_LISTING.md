## Description

```text
Glim Desktop Island is a development preview of a compact Windows desktop companion for coding-agent workflows.

Try a floating pill that expands into a detailed panel, with smooth transitions and system-tray controls to show, hide, recenter, or quit the island.

Glim is being developed for Claude Code CLI and Codex CLI workflows in VS Code. Automatic agent setup, live subscription usage, and reliable return-to-terminal behavior are still in development. This build is intended for early interface evaluation and is not yet a complete agent monitor.

Requires Windows 11 (x64) and Microsoft Edge WebView2 Runtime.
```
