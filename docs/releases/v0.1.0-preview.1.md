# Glim 0.1.0 — Windows development preview

The first downloadable Windows x64 preview of Glim's floating desktop island.

**This is an unsigned, incomplete development preview.** Windows may warn about or block it. Automatic agent setup, live subscription usage and fully validated Return to agent behavior are not available yet.

## Download and install

Download **Glim_0.1.0_x64-setup.exe** from the release assets, run setup, then open **Glim** from Start. Installation is per user. The packaged app does not need Rust, Node.js or C++ Build Tools; setup may download Microsoft's WebView2 runtime if needed.

The installer includes the native hook helper and VS Code companion package. Installing Glim does not install the extension or change Claude/Codex settings automatically. The island will remain quiet until session hooks are configured; the browser preview is available separately for sample data.

## In this preview

- Compact and expanded island, session rows, attention previews and stale-reading labels.
- Tray controls for showing, hiding, repositioning and quitting.
- Single-instance startup and persisted metadata discovery.
- A fix for initial display after restarting the native app.

## Verification and remaining work

Nine TypeScript tests and four Rust collector tests pass. Native checks covered eight synthetic sessions, approval/response previews, stale readings, duplicate launch, quitting and reopening saved sessions. These checks used isolated test data, not live provider integration.

Clean-machine installation/upgrade/uninstall, trusted signing, real CLI compatibility, exact VS Code foreground routing, monitor/DPI behavior and full focus/hit-region validation remain pending. This prerelease is not a stable release.

`SHA256SUMS.txt` contains the installer checksum. Checksums verify file integrity; they are not a code-signing certificate.
